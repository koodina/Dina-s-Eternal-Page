# The Eternal Page

dina's personal site: everything I've made for the Phaidei fandom, plus a little bit about me.

- `index.html`: all the words. Each section has a comment above it.
  - Foreword (the book): each `<div class="spread">` is one page. Copy one to add a page.
  - Chapters: each `<article class="work">` is one site. Add `flip` to its class to put the window on the right.
- `script.js`: the 12 memories on the wheel are at the very top in `MEMORIES`.
- `style.css`: all the colors are at the top in `:root`.
- `images/`: screenshots.
